Backend में AI API आपके "/api/ask" endpoint में OpenAI Responses API इस्तेमाल किया जा सकता है। उदाहरण के लिए: import OpenAI from "openai"; const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY }); export default async function handler(req, res) { try { const { question } = req.body; const response = await client.responses.create({ // नवीनतम उपलब्ध मॉडल को यहां रखें model: "gpt-6-astra", instructions: ` आप भारत के किसानों के AI सहायक हैं। हमेशा सरल हिंदी में जवाब दें। फसल, मिट्टी, सिंचाई, खाद, कीट और रोग के बारे में व्यावहारिक सलाह दें। यदि जानकारी निश्चित नहीं है तो किसान को कृषि विशेषज्ञ से जांच कराने की सलाह दें। `, input: question, // नवीनतम जानकारी के लिए web search tools: [ { type: "web_search" } ] }); res.status(200).json({ answer: response.output_text }); } catch (error) { res.status(500).json({ error: "AI सेवा में समस्या हुई" }); } } ध्यान दें: OpenAI की वर्तमान API documentation में "gpt-6-astra" उपलब्ध मॉडल के रूप में दिख रहा है; मॉडल IDs समय के साथ बदल सकते हैं, इसलिए production में उपलब्ध मॉडल सूची/दस्तावेज़ देखकर मॉडल चुनना बेहतर है। अगर आप चाहें तो इसी को अगले चरण में पूरा working website (HTML + Node.js backend) बनाकर, जिसमें फसल की फोटो upload करके रोग पहचान, मौसम, और भारत की सरकारी किसान योजनाएँ भी हों, तैयार किया जा सकता है।
